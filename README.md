# Продуктовая аналитика цифрового кошелька

Портфолио-проект по анализу клиентской базы цифрового кошелька с использованием **Python, PostgreSQL, SQL и Power BI**.

**Автор:** Осим Темурхонов  

## Дашборд

![Страницы Power BI](dashboard/screenshots/00_dashboard_pages.png)

## Основные результаты

- 7 000 уникальных клиентов.
- Общий LTV — 3,58 млрд единиц датасета.
- Средний LTV — 511,92 тыс. единиц датасета.
- High Value at Risk — 2 208 клиентов и 43,83% общего LTV.
- Champions — 1 291 клиент и 34,76% общего LTV.
- Эти два сегмента вместе содержат 49,98% клиентов и формируют 78,59% LTV.
- В Critical-группу удержания вошли 552 клиента со средним LTV 1,26 млн.

## Что сделано

1. Проверка качества данных.
2. Создание возрастных и поведенческих признаков.
3. RFM-сегментация.
4. Расчёт очереди клиентов для удержания.
5. Загрузка обработанных данных в PostgreSQL.
6. SQL-анализ с CTE, оконными функциями и представлением.
7. Шестистраничный дашборд в Power BI.

## Важные ограничения

- Датасет синтетический.
- Валюта в источнике не указана.
- `Inactivity_Risk` — аналитическая эвристика, а не подтверждённый отток.
- `LTV` почти полностью определяется `Total_Spent`, поэтому модель прогнозирования LTV с этим признаком создала бы утечку целевой переменной.
